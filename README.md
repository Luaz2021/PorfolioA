## 🛠️ Stack Tecnológico

* **Estructura Semántica:** HTML5 moderno y accesible.
* **Estilos & Diseño:** Tailwind CSS (vía CDN) + CSS personalizado (\css/styles.css\ y \css/responsive.css\).
* **Iconografía:** Lucide Icons.
* **Tipografía:** Google Fonts (\Inter\).
* **Interactividad:** JavaScript nativo (\js/script.js\) con scroll suave, filtrado y modales.
