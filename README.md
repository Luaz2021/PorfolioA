# Portafolio Personal & Hoja de Vida 2026

¡Hola! Soy **Saúl Alexander Martínez (Luaz)**, estudiante de DAM en la Universidad Europea y Técnico en Desarrollo de Software por SENATI. Este repositorio contiene el código fuente de mi portafolio web personal, enfocado en mi perfil como desarrollador **Backend**.

---

## Tecnologías y CDNs Utilizados

* **Estructura:** HTML5 semántico limpio.
* **Estilos:** Tailwind CSS (vía CDN) + CSS personalizado (`css/styles.css` y `css/responsive.css`).
* **Iconografía:** Lucide Icons.
* **Tipografía:** Google Fonts (Inter).
* **Interactividad:** JavaScript nativo (`js/script.js`).

---

## Proyectos Destacados

1. **Autocheck:** App móvil enfocada en la gestión y control preventivo de coches, seguimiento de aceite, kilometraje y mantenimiento vehicular *(Flutter, Spring Boot, PostgreSQL)*.
2. **Sistema de Préstamos:** Control de inventario y registro de préstamos de artículos mediante Java puro, JDBC, servidor HTTP propio y MariaDB.
3. **E-commerce Base:** Plataforma de comercio electrónico con interfaz diseñada por IA y arquitectura backend robusta para catálogo y transacciones *(Spring Boot, MySQL)*.
